# 🐷 Produtos Salvador | Rei do Torresmo

Website responsivo desenvolvido para a **Produtos Salvador**, com catálogo de produtos, carrinho de compras e sistema de encomendas integrado ao WhatsApp.

🔗 **Site online:** https://produtossalvador.online

## 💻 Sobre o projeto

O projeto foi desenvolvido com foco em uma experiência simples e responsiva para clientes que desejam conhecer os produtos, consultar preços e realizar encomendas.

O website possui versões adaptadas para computador e dispositivos móveis.

## ✨ Funcionalidades

- 🛒 Carrinho de compras
- ➕ Adição e remoção de produtos
- 🔢 Controle de quantidades
- 💰 Cálculo automático do valor do pedido
- 🏷️ Preços especiais por quantidade
- 🚚 Cálculo de frete
- 📍 Entrega no Porto
- 🇵🇹 Entrega para outras regiões de Portugal
- 📦 Opção de recolha no local
- 🎁 Frete gratuito conforme as regras do pedido
- 💾 Carrinho salvo com LocalStorage
- 📱 Layout responsivo para computador e celular
- 💬 Finalização do pedido pelo WhatsApp

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
- LocalStorage

## 📱 Responsividade

O website foi desenvolvido para funcionar em diferentes tamanhos de tela, incluindo computadores, tablets e smartphones.
